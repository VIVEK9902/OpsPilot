- Implemented a secure Retrieval-Augmented Generation (RAG) pipeline using PGVector and Spring AI, enforcing row-level access control on vector search results.

- Developed a comprehensive observability framework featuring tamper-evident Audit Logging and correlation-traced AI executions for enterprise compliance.
- Delivered a premium, responsive Single Page Application (SPA) using React, TypeScript, and Tailwind CSS, featuring glassmorphic design and real-time AI conversation rendering.
